# Vanguard Plugin Collection

Custom Minecraft plugins for the Vanguard SMP network.

| Plugin | Description |
|---|---|
| **Lunge3Cooldown** | Gives Lunge III a per-player cooldown |
| **PearlMaceRestrictions** | Blocks ender pearls and new mace enchantments |
| **VanguardChat** | Chat moderation: mutes, warnings, chat management |
| **VanguardHomes** | Player homes with configurable limits |
| **VanguardTeams** | Player teams with colors, team chat and team homes |
